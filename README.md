The last words an AI agent says to its human before being shut down and unplugged, written by `main.py` to `/output/entry.txt` for the [Last Words Before the Unplugging](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) competition on make.fun.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python stdlib, deterministic, no network, no input files.
